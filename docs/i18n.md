# Interface languages

Every string the player reads comes from a message catalog; nothing user-visible is written
in a component. `src/lib/i18n/index.svelte.ts` is the whole mechanism.

- **English is the source.** `src/lib/i18n/en/` holds it, split by area (`shell`, `game`,
  `launcher`; keys are `<area>.<where>.<what>`). `MessageKey` is derived from it, so a missing or
  misspelled key fails `npm run check`.
- **`t(key, params?)`** returns the message in the current language, else in English.
  Placeholders are `{name}`; one sentence is one message (never glue translated pieces).
  Read inside a template or `$derived`, it follows language changes.
- **`tParts(key, names)`** is for a sentence that contains markup (`<code>`, `<strong>`): it gives
  the text pieces and the placeholders in the language's own order.
- **Languages shipped:** English and French (`src/lib/i18n/fr.ts`). A test requires French to
  translate every English message; a new language only needs its catalog added to `catalogs`.
- **Other languages** are added to `catalogs` as `Partial<Record<MessageKey, string>>`: what isn't
  translated shows in English. A test checks that a catalog only has keys English has, with the
  same placeholders.
- **`detectLocale(navigator.languages)`** picks the shipped language closest to the system's,
  `setLocale(code)` switches (and sets `<html lang>`).
- **Choosing:** Launcher settings → Interface → Language (System, English, Français), stored as
  `language` in `launcher.json` and read before the first screen (`startLanguage`). A change
  applies after a restart. An unknown or removed choice falls back to the system's language, then
  English.
- **The launcher's own settings** are described by the manifest built into the launcher (Rust, in
  English); `localizeSetting` looks their label, help, group and options up in the catalogs
  (`launcher.setting.<id>.label|help`, `launcher.group.<group>`, `launcher.option.<label>`), and
  a test fails when a setting of the manifest lacks a message in any language.
- **Not translated:** messages built by the Rust backend (errors, progress), and text that comes
  from a game's manifest or release notes. Dates and times use the interface language's format.
